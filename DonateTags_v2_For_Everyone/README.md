# DonateTags v2 — For Everyone

Это исходники версии 2.3.1 без проверки прав OP. Любой игрок с Admin’s Book может управлять рангами, заморозкой и журналом действий.

**Важно:** кнопка GitHub «Download ZIP» скачивает исходники, а не готовый `.mcaddon`. ZIP нельзя просто импортировать в Minecraft.

Структура:
- `BP/` — behavior pack, скрипт и предмет.
- `RP/` — resource pack.
- `RP/textures/items/admins_book.png.base64` — изображение книги в текстовом Base64. Его нужно декодировать в `admins_book.png` перед упаковкой.

Чтобы собрать аддон: упакуйте содержимое `BP/` в ZIP и переименуйте в `.mcpack`; отдельно упакуйте содержимое `RP/` (после декодирования PNG) в другой `.mcpack`. Затем поместите оба `.mcpack` в ZIP и переименуйте ZIP в `.mcaddon`.

Версии BP/RP и зависимости согласованы: 2.3.1. Проверка OP отсутствует. В Minecraft сборка пока не тестировалась.
